## 项目：终极翻译（PC 端划词翻译工具）— 方案调研

### 目标
Windows 划词翻译（英/日 → 中），全局快捷键触发，鼠标旁轻量悬浮窗，核心指标=自身内存占用最低（模型内存不计入），必须走 GPU 保证速度，优先内置模型（不依赖 HYBall.exe）。

- 目标模型：腾讯混元 Hy-MT2-1.8B Q8_0 GGUF（1.91GB），位于 `C:\Users\17535\Desktop\杂项\HYBall_Windows_x64_v1.0.2\models\`
- 推理后端：llama.cpp b11118（`llama/` 目录），OpenAI 兼容 API
- **可独立运行验证成功**：从 `llama/` 抽取 11 个文件 + `_internal` 里的 UCRT 依赖（api-ms-win-crt-*, ucrtbase, VCRUNTIME140*），即可脱离 HYBall 启动 llama-server
  - 必需：llama-server.exe, llama-server-impl.dll, llama-common.dll, llama.dll, ggml.dll, ggml-base.dll, ggml-cpu-*.dll, libomp.dll, mtmd.dll(必须，否则 load 失败), ggml-vulkan.dll(43MB, GPU 必需)
  - 踩坑：缺 mtmd.dll 时只报 `error while loading shared libraries: ?`，无明确 dll 名
- 性能实测（i9-14900HX / RTX 4060 Laptop 8G / 16G RAM）：

  |---|---|---|---|
  | CPU 8 线程 | 75 tok/s | 18.9 tok/s | 1.43s |
  | Vulkan -ngl 999 | 1344 tok/s | 83 tok/s | 0.52s |
  | Vulkan + ctx512/np1 | - | 82 tok/s | 0.33s |
- 显存占用：约 2.4GB（模型），桌面基线后总 3.8-4.0GB
- 冷启动到 listening：约 3.2s（支持"空闲卸载、按需拉起"策略）
- 采样参数（官方推荐）：temperature 0.7 / top_p 0.6 / top_k 20 / repeat_penalty 1.05
- Prompt 模板：`将以下{语言}文本翻译为{语言}，注意只需要输出翻译后的结果，不要额外解释：\n\n{text}`
- 翻译质量：英→中、日→中 均正确且无多余解释
- ctx=512 + np=1 不影响短句速度；np 默认 4 会浪费 4 份 KV cache

## 实现结果（已完成并端到端验证）

### 产物

### 实测数据
- 主程序：WS 16.4MB / **Private 3.54MB** / 8 线程
- llama-server：WS 1543MB / Private 1639MB（Q6 权重 1406MB，非模型开销约 230MB）
- 显存约 3.0GB（含桌面基线），模型约 1.8GB
- 速度：Q6 112.8 tok/s（Q8 95.6），单句端到端 0.07-0.2s；冷启动 3.2s

### 模型选型结论（实测）
- **1.25bit / 2bit 不可用**：依赖腾讯 STQ kernel（llama.cpp PR #22836 未合并），gguf 解析层直接失败（tensor offset 不匹配），官方示例也只用 `-ngl 0` CPU
- FP8 / 原始 FP16 需 PyTorch/vLLM 栈，排除
- 可用：Q4_K_M / Q6_K / Q8_0；用户选 Q6_K

### 踩过的坑（重要）
1. **MinGW Makefiles 不支持中文路径**（工作目录叫"终极翻译"），必须 `-G Ninja`
2. llama-server 最小子集必须含 `mtmd.dll`，缺它只报 `shared libraries: ?` 不报文件名；另需从 `_internal` 补 UCRT
3. **SSE 首帧 `content` 为 `null`**，解析必须判断冒号后是不是引号，否则把后面的 `"created"` 字段名当译文（每句开头多 created）——最初误判成"模型幻觉/温度过高"，实为解析 bug
4. `DT_CALCRECT` 高度不含最后一份行距，中文末行被切，需补一行余量
5. 截图脚本必须 `SetProcessDPIAware()`，否则 GetWindowRect 拿逻辑坐标、PrintWindow 画物理像素，缺右下角
6. Windows ini API 按 ANSI 写文件，中文值 UTF-8 打开乱码 → 目标语言不落盘
7. 累积译文不能用函数内 `static`，否则第二次划词带上一次译文
